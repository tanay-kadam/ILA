# Historical server source

`manifest.json` inventories 132 server code/config/test files from 2026-10-20.
It points to existing maintained files when their Git bytes match the server
checksum. Ten differing versions are retained here at their original relative
paths. Each entry records its original size and SHA-256.

These are provenance copies, not recommended replacements for maintained source.
They can contain older behavior or known bugs described in `docs/`. The snapshot
does not prove which code version each historical experiment actually executed;
consult the run-specific code hashes and recorded limitations.
